We're happy to talk with you! Here's how to reach us:

## E-Mail
We are open to discuss sponsorships and other private requests through our email.
Please do not report any bugs / feature requests here - they will be ignored and deleted.

[github-admins@emkraan.com](mailto:github-admins@emkraan.com)

## GitHub
For questions, bug reports and feature requests, please open an issue on our
[GitHub repository](https://github.com/Emkraan/muninn/issues/new/choose).
This is the best place to reach the maintainers and the community.

## Security
Please do not report security vulnerabilities through public GitHub issues.
Instead, report them privately through
[GitHub Security Advisories](https://github.com/Emkraan/muninn/security/advisories/new).
